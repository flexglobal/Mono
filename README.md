# Mono — официальный промосайт

Адаптивный промосайт браузера Mono, выполненный на обычных HTML, CSS и JavaScript. Работает без npm, сборщика, CDN, API и регистрации.

## Запуск

Откройте `index.html` двойным щелчком или загрузите содержимое папки на любой статический хостинг (Vercel, Netlify, GitHub Pages, обычный nginx и т. п.). Файл `index.html` должен лежать в корне сайта вместе с папками `assets`, `css`, `js`.

Для локального HTTP-просмотра можно выполнить в папке сайта:

```bash
python -m http.server 8080
```

И открыть `http://localhost:8080`.

При смене релиза достаточно обновить ссылку в `index.html` и `Mono_Website_Standalone.html`.

## Состав

- `index.html` — контент и семантическая HTML-разметка.
- `css/style.css` — фирменный дизайн, адаптивность, обе темы.
- `js/main.js` — интерактивность, навигация, меню, демонстрация экранов и диалог скачивания.
- `js/config.js` — адрес установщика.
- `assets/` — оптимизированные скриншоты из Mono и логотип.

## Возможности промосайта

- Адаптивность: телефон, планшет, десктоп.
- Светлая и тёмная темы с сохранением выбора.
- Закреплённое меню и мобильная навигация.
- Переключаемые скриншоты Mono с управлением клавишами.
- Анимации появления и индикатор прокрутки, поддержка `prefers-reduced-motion`.
- FAQ-аккордеон, модальное окно скачивания и управление фокусом.
- Нет внешней аналитики, рекламы или обязательных внешних запросов.

## Важно

Скриншоты отражают разработанные интерфейсы проекта Mono. Некоторые функции самого браузера могут находиться в стадии тестирования. Сайт не проверяет доступность функций настольного приложения и не гарантирует скорость или совместимость отдельной сборки.

## Публикация на Vercel

Создайте **отдельный новый** Vercel-проект для промосайта Mono и загрузите в него содержимое этой папки. Framework Preset: `Other`, Build Command не нужен, Output Directory оставьте пустым. Файл `vercel.json` добавляет базовые защитные HTTP-заголовки.

**Не заменяйте файлы существующего Vercel-проекта Mono Messenger**: там находится API сигнализации и Redis, а этот сайт — отдельная статическая страница.
